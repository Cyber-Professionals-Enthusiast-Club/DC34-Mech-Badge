DC 34 MechBattle Badge

---------------

This is the second iteration of the code that supplies menu and game logic for the CPEC DC34 badge offering.

Written in C, this code houses a basic menu function, and basic AI to test top-level concepts for implementation as a battle calculator.

This is not final.
